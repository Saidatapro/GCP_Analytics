
# 📈 GCP-Based Business Analytics Project Using BigQuery + SQL

This project simulates a Google Cloud-native business analysis workflow focused on KPI extraction, customer segmentation, and revenue insights using BigQuery and SQL as the primary tools.

## 🚀 Project Overview

- Performed data analysis and business reporting using Google BigQuery
- Used SQL for querying customer behavior and order trends
- Designed dimensional models using analytical functions and CTEs
- Delivered insights for decision-making using Looker Studio dashboards

---

## 🛠 Tech Stack

- **Google Cloud Storage (GCS)**: Raw data staging
- **BigQuery**: Scalable analytics and SQL-based transformations
- **SQL**: Primary language for KPIs and segmentation logic
- **Looker Studio**: Dashboard and reporting layer
- **Google Cloud IAM**: Controlled data access
